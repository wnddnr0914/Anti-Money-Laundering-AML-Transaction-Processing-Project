# 의심거래보고서(STR) 초안

## 1. 거래 개요

| 항목 | 내용 |
| --- | --- |
| 대상 거래 | TX000003 |
| 송신 → 수신 | B → D |
| 거래 시각 | 2022-11-01 10:07:00\+00:00 |
| 대상 거래 금액 | 2,800 USD |
| GNN 의심 점수 | 0\.81 |
| 알럿 여부 | 대상 |
| 탐지 모델 버전 | fraudgt-mock-v1 |
| 탐지 결과 출처 | 예시\(Mock\) |
| 제공된 거래 수 | 3건 |
| 제공 거래의 최초·최종 시각 | 2022-11-01 10:01:00\+00:00 ~ 2022-11-01 10:07:00\+00:00 |
| 주변 거래 조회 설정 | 2홉 / lookback\_days=7 \(전체 거래 포함을 보장하지 않음\) |

입력 범위 및 처리 안내:
- amount/currency는 API 기재 거래 금액이며, 실제 수취액·환전액은 별도로 확인하지 않았습니다\.
- 조회 시작·종료 시각이 없어 lookback\_days로 분석 기간을 추정하지 않았습니다\.
- 주변 거래의 생략 여부가 제공되지 않았습니다\. 집계는 제공된 거래 목록에 한정합니다\.
- 탐지 모델 버전에 mock 표시가 있어 예시 탐지 결과로 표시합니다\.
- 유형 분석은 검증 완료 상태가 아니므로 후보 정보로만 표시합니다\.

## 3. 의심 근거

**관찰 사실**

대상 거래는 B에서 D로 이루어진 송금이며, 금액은 2,800 USD이다\.

근거 거래: TX000003

**관찰 사실**

대상 송금 직전에는 2 건건의 관련 입금이 있었고, 유입 상대 계좌는 2 개개이며, 관련 유입 거래의 기재 금액 합계는 3,000 USD이다\.

근거 거래: TX000001, TX000002

**관찰 사실**

마지막 관련 입금과 대상 송금 사이의 간격은 240\.0 초이다\.

근거 거래: TX000002, TX000003

**추가 검토 사유**

대상 계좌로의 유입이 짧은 시간에 이어진 뒤 송금이 발생했으므로, 제공된 거래만으로는 자금의 성격이나 거래 목적을 확인하기 어렵다\. 정상 정산이나 단순 자금 이동과 같은 다른 설명이 있을 수 있으나, 이를 뒷받침하는 증빙은 제공되지 않았다\.

근거 거래: TX000001, TX000002, TX000003

**추가 검토 사유**

관련 입금의 실제 수취액, 입금 사유, 계좌 소유 관계, 거래 상대방과의 관계를 확인하지 못해 자금 흐름의 배경을 판단하기 어렵다\. 추가로 거래 메모, 계약서, 정산 자료, 계좌 명의 확인 자료가 필요하다\.

근거 거래: TX000001, TX000002, TX000003

**모델 설명 근거**

예시 XAI 결과\(Mock\) / 방법: GNNExplainer / 설명 ID: EXP000003 / 모델 버전: fraudgt-mock-v1

## 4. 미확인 사항

- 관련 입금의 실제 성격을 확인할 수 있는 입금 사유 또는 거래 메모
- 대상 계좌와 관련 입금 계좌들 사이의 관계를 확인할 수 있는 명의 및 거래 관계 증빙
- 대상 송금의 목적을 확인할 수 있는 계약서, 정산 내역, 청구서 등 증빙
